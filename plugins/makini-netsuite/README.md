# makini-netsuite

Connects the agent to the user's Oracle NetSuite account through the Makini MCP server at `https://mcp.makini.io`.

Install in Claude Code:

```
/plugin install makini-netsuite --marketplace makinihq/agent-plugins
```

- Sign in with your work email. A new address gets a Makini account and workspace on its first sign-in.
- Connect NetSuite when the agent asks; it gives you a link.
- Reads run on their own. Changes run through a separate write tool, only when you ask for them.

Your workspace's administrator decides which operations are enabled.
